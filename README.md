# 📊 TikTok Virality & Engagement Analytics Dashboard

![Dashboard Preview](dashboard_preview.png)

## 📌 Project Overview
This project presents an interactive **Tableau Dashboard** focused on analyzing TikTok video performance metrics, engagement patterns, and viral dynamics. The main objective is to identify key drivers of video virality, viewer retention, and interaction behavior (likes, comments, shares) to support data-driven content strategy optimization.

---

## 🔑 Key Features & Insights
- **Executive KPI Panel:** Instant overview of Global Views, Total Likes, Engagement Rate, and average Share-to-Like ratios.
- **Virality Matrix (Logarithmic Scatter Plot):** Identifies "Dark Virality" trends by mapping **Share-to-Like Ratio** against total views on a logarithmic scale.
- **Trend Lifespan & Safety Decay:** Dual-axis visualization showing interaction metrics alongside content volume over time.
- **Interactive Filtering:** Drill-down capabilities using Tableau filter actions and dark-mode container layouts.

---

## 🛠️ Tools & Technologies Used
- **Tableau Public / Desktop:** Advanced Container Layouts, Dual-Axis Charts, Logarithmic Scaling, Parameter Controls.
- **Git & GitHub:** Version control and public repository documentation.
